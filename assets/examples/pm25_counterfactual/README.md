# PM2.5 Counterfactual Framework Example

This example demonstrates RouteGraph's workflow for a four-panel scientific technical route figure.

## Run

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\templates\pm25_counterfactual_framework.ps1
```

The generated PPTX will be saved to the Desktop.

## Review Priority

After generating the PPT, take a screenshot and check:

1. Arrow topology;
2. Arrow direction;
3. Arrow style;
4. Text wrapping;
5. Delta symbol;
6. Panel spacing.
